## 后续新增接口规则

1. 在 `H` 内定义独立方法，使用 `@route('GET'/'POST', '/api/...')` 声明，签名为 `(self, ctx)`。
2. 同一方法可以声明多个明确的路径别名，不新增前缀分发链。
3. 成功或失败均明确发送响应，建议 `return self._send(...)`；不得在已开始的流式响应后尝试再发送错误正文。
4. 新接口同步更新 `tests/http_route_contract.json` 并添加针对行为的 HTTP 测试。
5. 请求体由业务函数读取一次；禁止全局统一 JSON 解析破坏上传和二进制接口。
