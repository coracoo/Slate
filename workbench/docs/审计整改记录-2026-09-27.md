# 审计整改记录（2026-09-27）

## 范围

- 审计来源：`Slate_审计与整改包_eeaef41e.zip`
- 审计基线：`eeaef41e`
- 本轮处理：F01–F09、F12、F13
- 暂缓：F10、F11

本轮只修复可以由现有数据契约确定的问题。未迁移项目数据，也未改写已有图片、视频和平面图文件。

## 已完成

### F01、F02：资产仓库与锚定

- 统一人物、场景、道具正式文件映射；单类提炼读取并合并正式中文档案。
- 单类提炼失败或返回空结果时保留其他集及其他实体。
- 自动锚定固定使用正常审核门槛；存在阻断项时不再反向强制锚定。

### F03–F05：表演、时长与依赖失效

- 已采用表演的 `visible_action` 进入实际图片和视频请求。
- 视频请求在付费生成前执行统一时间预算检查；区间越界、对白超长和 V 总时长不足均返回结构化冲突。
- 分镜生成不再把超长对白静默压到镜尾 0.8 秒。
- 指纹覆盖实际消费的机位、场景、声音和完整表演包；新增字段仅在真实存在时扩展指纹，保留旧分镜历史指纹兼容。

### F06：图片生成记录溯源

- 补缺模式遇到已有图片时，保留原始 prompt、模型、Skill 和参考图记录。
- 新目标写入 `desired_spec`；当前图片与目标不一致时记录 `stale_reasons`，不再把旧图伪装成新配置产物。
- 人物状态图保留集次、阵营及派生关系。

### F07、F13：系统提示词与预览

- 内置任务契约始终保留；用户在提示词中心保存的内容作为策略补充追加，不能覆盖 Schema、写权限和硬约束。
- 预览和真实调用共用同一个编译函数。
- 修复归属类预览中 JSON 大括号导致的格式化异常。

### F08：生成与采用分离

- 普通图片、视频生成成功后只进入候选状态。
- 取消“槽位为空即自动采用”；采用继续走明确操作，与宫格和重拍保持一致。

### F09：宫格编译

- 宫格只使用用户设置的行列和画幅，不再追加固定 3×3、16:9 指令。
- 参考图先完整解析，再按所选模型能力校验；超限直接阻断，不再静默截断。
- 宫格请求沿用项目制作规格中的默认画幅。

### F12：平面图审核状态

- 平面图清单携带 `_judge` 结果和 `approval_state`。
- 明确被语义审核拒绝的平面图可保留编辑，但不会被自动选择为制作空间锚点。
- 没有历史判官字段的旧平面图维持兼容，避免无迁移依据时整批失效。

## 暂缓项

### F10：全剧来源覆盖与分集白名单

该项需要新增原作片段覆盖矩阵、全局实体注册表、分集允许集合及 `change_request` 审批契约。现有数据无法可靠推导这些权威关系，因此本轮未用启发式规则补写。

### F11：证据支持等级

该项需要把现有 `verified` 拆成 `source_located`、`claim_supported`、`human_approved`，并迁移证据坐标、引用哈希和历史资产状态。当前审计没有指定旧数据迁移及 UI 审核规则，本轮不改变已有证据语义。
