# 提示词工程契约

提示词版本：`PROMPT_VERSION = 1.12`。本文描述代码实际消费边界，分镜 JSON 仍是镜头事实的唯一来源。

## 分层与优先级

| 层 | 权威来源 | 允许影响 | 不得覆盖 |
| --- | --- | --- | --- |
| 输出契约 | `prompt_modules.py`、`production_prompts.CONTRACT` | 字段、类型、输出媒介 | 不允许 Skill 改为另一种输出格式 |
| 剧情与镜头事实 | 已锚定设定、分集正文、分镜 | 身份、事件、台词、时长、机位、走位 | 风格、案例、演员候选不得改写 |
| 角色创作背景 | `素材/人物.json` | 人物动机、关系、语言与行为基线 | 不直接当成当前镜头已经发生的动作 |
| 方法偏好 | 系统补充、编剧/导演/表演 Skill、知识卡 | 当前任务内的创作方法 | 输出契约、角色知情范围与剧情事实 |
| 生图画风 | `skill_lib` 的当前画风选择 | 绘画媒介、渲染与笔触 | 主体身份、结构与构图 |

用户系统补充经过 `compile_system_prompt` 追加，内置契约保留，并在末尾声明补充适用边界。这是提示词约束；执行端仍须通过 JSON 解析、实体引用与镜头契约校验，不能只依赖模型服从。

## 参考帧、视频与宫格

- `prompt_image` 描述一个可辨认的静止瞬间；不承担视频动作过程或宫格布局。
- `prompt_video` 描述本镜连续动作与时序，台词不变。
- `prompt_grid` 描述多格故事板的行列布局和逐格瞬间，遵循本镜顺序，不新增剧情。它与静帧、视频提示词分别生成；已有关键帧的确定性排版是另一个输出方式。
- 分镜生成一次输出包含三类提示词和 V 分组的 JSON。格式由 `production_prompts.CONTRACT` 单点定义，旧 `prompt` 只作为静帧兼容视图。历史缺项从分镜页按选中分集批量补齐，不用单一提示词复制填充。
- `compile_stage_prompt(stage="asset_image")` 必须提供 `kind=character|scene|prop` 与主体描述，调用资产构图装配器；不得经过剧情单帧装配器。人物五视图、场景空镜、单一道具各自使用资产契约。
- 已重写的镜头提示词跳过旧剧情内容补充，但当前选择的生图画风仍注入一次；同时识别 `prompt_image_source` 与旧 `prompt_source`。

## 角色中心接入

角色中心保存 `素材/人物.json`，不新建第二套角色事实来源。`storyboard_prompt` 接收完整人物列表，并将以下字段放入独立的“人物创作背景”输入块：

`biography`、`bio_language`、`bio_crack`、`bio_pressure`、`bio_address`、`bio_arc`、`relations`、`acting`。

`sheet_prompt`、外观长文和概念图不随此背景块展开；镜头仍用稳定 `@character:id` 引用。分镜调用方当前已传完整人物列表，无须增设接口。扩写侧通过 `story_units.units_block` 投影小传、关系与演绎，演员准备从同一档案投影角色卡；镜内人工覆盖和锁定字段保留。

`compile_shot` 的表演文本、结构化 `action_by_actor` 与 `voice_notes` 共用采用模式、ready 状态、来源新鲜度与本镜演员范围检查。空镜不回填全剧演员；旁白不进入角色卡。图片仅投影一个结束节拍的可见姿态，不写时间区间、心理动机或声音；视频音频出口声明支持声音时才将配音备注写入最终文本。

## 回归与限制

新增 `test_prompt_engineering_boundaries.py` 覆盖：候选过期/未采用不泄漏、空镜不加人、静帧表演、画外演员与旁白过滤、资产阶段构图隔离、重写画风单次注入、角色背景传递、纯 JSON 输出、策略边界与画风优先级。

旧格式仍会从说话人、站位等字段推断本镜演员；该推断无法保证说话人实际入画，精确可见范围应以分镜显式引用与画格记录表达。没有来源 hash 的历史 ready 表演维持原兼容策略。未执行真实模型的提示词质量对比，不声称离线断言能够证明生成效果。


## 规划完成条件

全剧规划先生成大纲、人物名册、分集大纲与埋线，再补人物小传和演绎要点、场景约束与道具边界，核对确认后才进入正文扩写。人物 `biography` 是独立小传，`bio_*` 五项是演绎约束；两者都经生成、落盘、补缺与审核链路。受规划管理的项目，在用角色缺项会阻止确认与扩写；未引用历史档案不阻断。导入稿与旧版非规划项目保留兼容读取。

旧规划缺少小传时使用「补全规划缺项」，已填写和人工保护字段保留；新增内容须重新确认，不自动改写分集正文。
