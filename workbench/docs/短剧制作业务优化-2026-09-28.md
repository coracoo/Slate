# 短剧制作业务优化

## 制作主线

构想或导入原稿 → 制作规格 → 分集与全剧设定 → 单集正文 → 素材投影与派生 → S 转场镜头 → V 分镜视频 → 集视频。

- 构想创作：统一生成分集卡、剧情分段、伏笔和实体设定；确认、锚定后逐集扩写。
- 导入创作：保存原稿、拆分集；可按需反推设定，或直接推进素材和分镜。
- 分集卡负责本集目标、节拍和引用；正文负责具体场景、行动和对白。单集扩写不重新规划全剧。
- 人物、场景和道具始终复用项目档案。分镜 JSON 是镜头事实来源，表演、平面图、画风只能按职责补充。

## 本次已落地

### 剧本工作区

| 问题 | 调整 |
| --- | --- |
| 构想、原稿、规格和正文纵向堆叠，阅读要打开抽屉 | 同页分成「设定与制作规格」「分集与正文」；分集列表与正文并排，窄屏上下排列 |

| 目标集数存在两个输入 | 统一使用制作规格中的目标集数；未填写时首次规划默认 6 集，既有分集保持集数 |
| 未保存规格或原稿就点分集，生成用到旧值 | 分集与扩写前保存规格；导入拆分集先保存编辑中的原稿 |
| 单集扩写优先用旧大纲重建分集 | 单集扩写只读取最新分集卡，保留节拍、伏笔、引用、其他集正文及顶层元数据；不重写大纲 |
| 导入剧本扩写单集仍要求另写构想 | 既有分集可从导入正文获得背景；缺少集号则在模型调用前停止 |
| 字体小、正文等宽显示、选集刷新丢失 | 正文按段落阅读，场标题分隔，限制行宽；选集按项目记忆 |
| 分集、扩写与全剧设定能在同页同时写入 | 写入入口共享忙碌状态；切换项目停止后续批量扩写，等待中的拆分任务不会写入新项目 |
| 独立编剧策略在全剧设定入口被旧 script 键挡住 | 全剧设定直接读取叙事结构、剧情节奏、连续性策略组合 |

### 演员环节

演员层是表演连续性的增强环节。对于人物关系持续变化、台词信息差、隐瞒与揭露、情绪反转的短剧，它能把「角色此时知道什么、想要什么、怎样表现」落到镜内动作，而不是只给一个情绪形容词。

建议顺序：分镜事实稳定 → 准备角色理解 → 生成表演候选 → 人工采用 → 生成关键帧或视频。

- 不强制普通建立镜头、风景镜头、简单动作镜头执行演员生成。
- 不让演员层重写剧情、台词、镜头时长、运镜或资产外观。
- 图片仅取可见的一个动作状态，视频消费连续表演节拍；关键帧时间角色仍按现有首帧/尾帧契约执行。
- 配音由音色绑定与语音链负责；演员中的声线提示只是表演指导，不能替代角色音色资产。
- 已采用表演已经被当前关键帧和视频请求消费；本次增加采用/待更新状态、可见动作与声音摘要，以及前往创作生成入口。
- 修正「锁定」覆盖「过期/无效」状态的展示。锁定保护选择，不代表其来源仍有效。

表演文本评分只能用于筛选候选，不能作为最终成片质量评分。

### 平面推演

平面图表达空间关系：门窗、陈设、可走区域、人物位置、机位与路径；它不承担成片画风。

- PNG 与网页共用同一份陈设轮廓和门窗区间，修复门窗漏画、陈设旋转未生效、圆形陈设半径口径不一致。
- 网页使用等比米制视口和像素比例适配，减少空间形变与模糊；按当前场景适配，支持拖动与缩放。
- 标签增加底色并尝试避让；PNG 提高地面和线条对比度，路径增加方向箭头和估算比例尺。
- 平面页直接预览画布，避免每次跳到新窗口。
- 渲染器变化后，下一次复用会重建 PNG 缓存；HTML 需点击「刷新绘图」更新。重绘不调用 LLM。

坐标来自描述估算或已有镜头数据，因此比例尺标为「估算」；图面上方不能自动解释为真实地理北向。

## 全业务评估与后续优先级

### 单集改稿与制作追踪

- 已支持单集正文编辑、按集本机草稿保留、保存前正文对照与历史稿读取。历史版本读取只填入编辑器，保存时才更新权威分集 JSON。
- 保存使用内容修订基线，旧稿冲突保留编辑稿；已启动的扩写结果也不能覆盖期间保存的人工稿。
- 正文与保存基线来自同一次读取；扩写后的文本副本按权威 JSON 的最新稿同步。旧导入稿扩写一集时保留其他集原文切片。
- 改稿保留分集卡、伏笔和其他集正文，列出受影响分镜、S/V、已采用产物和引用素材的复核范围。不自动删除产物或重写素材。
- 新分镜记录本集正文指纹；旧分镜按改稿修订记录判断。修改 E1 不让 E2 因全局版本递增而误报过期；无法区分的旧全本分镜提示统一复核。
- 按集统计素材图、已采用关键帧、S 视频、V 视频和有效集视频。候选未采用、文件缺失、来源过期不计为完成；老绑定缺少来源指纹时列待复核。
- 演员页展示与请求相同的角色知情快照、已应用事件、事实来源和状态。未指定事件时点时明确提示沿用完整上下文，需要人工检查是否提前泄露未来事件。此视图不替代原文事实核验。

后续仍需建设：语义级改稿影响分析、可编辑的事件时点与原文锚点、单镜复核确认与实际视频表演评估。

| 优先级 | 环节 | 优化建议 | 完成标准 |
| --- | --- | --- | --- |
| 高 | 剧本修订 | 已落地本集正文编辑与历史对照；后续细化到语义级影响，而非整集复核 | 用户能改一句对白并看清具体哪些镜头需要调整 |
| 高 | 角色连续性 | 已展示镜头知情依据；后续增加事件时点编辑与原文锚点核验 | 同场不同镜不会突然知道未发生的事，候选可定位到依据 |
| 高 | 制作进度 | 已落地按集状态；后续增加跨集任务总览与从缺项继续入口 | 能从未完成集继续，已采用产物不会重复生成 |
| 高 | V 生成 | 展示成员 S 时长、实际模型可用时长、最终时间轴和参考顺序；修改时及时更新 | 提交前能看出时长伸缩、参考槽位与转场关系 |
| 中 | 素材派生 | 场景母图、时段/状态派生、人物状态、音色派生共享引用清单 | 既复用空间与身份，又能区分夜景/损坏/情绪等状态 |
| 中 | 平面推演 | 可编辑门窗/陈设/站位；基于平面图检查通路、视线、越轴，给出待确认点 | 用户可修一个位置，不必重新生成整个场景布局 |
| 中 | 表演评估 | 从文本候选比较延伸到生成帧/视频的动作、视线与情绪检查 | 文本评分与实际画面结果分别记录，不能相互替代 |
| 中 | 集视频 | 镜段采用后串联音色、台词时间轴、配乐与拼接；保留每段来源 | 集视频可定位到 V 与 S，改一个镜段只更新该段 |

## 提示词与调度边界

系统硬契约负责事实和输出结构；流程负责阶段、来源和产物；编剧策略负责结构/节奏/连续性；导演策略负责镜头表达；演员负责可见表演；视觉风格负责画面表达。各层仍由统一装配器组合。

当前继续使用程序管理明确阶段、LLM 完成创作与优化。外部 Agent 中控暂不进入默认链路：应先解决单集编辑、连续性证据和产物依赖，再比较 Agent 在同一输入、同一成本预算下是否减少人工修改。

## 验证范围

使用本地样例与模拟模型的定向回归、绘图几何检查和前端构建；未执行深度 smoke，未调用付费生图、生视频或剧本生成。画布和页面的实际业务使用仍应以用户审阅为准。
