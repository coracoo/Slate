# 生成执行与厂商收束

## 已确定的边界

用户决定：ChatGPT 一次一张；工作台负责提示词、参考图、队列、归属、导入，image-use 负责网页执行，chrome-use 负责浏览器连接。禁止回落 Codex 登录态。旧 Previs MCP、Widget、自研扩展退出运行和页面，历史项目数据保留。

每项固定 job_id、attempt_id、提示词快照、参考图顺序及哈希；每次启动独立生成请求，只接受一张图片。输出暂存、解码与比例校验、重复检查、任务快照复核、事务导入完成后，才推进下一项。错误、未知发送、进程中断一律暂停，不自动重发。

## 实施清单

- [x] 集中厂商目录与无损配置迁移：ComfyUI、ChatGPT、火山方舟、MiniMax、通义、阿里云、Gemini、可灵、OpenAI 兼容、Kimi、GLM、DeepSeek。

- [x] 环境页 chrome-use 安装指令、上游扩展下载、状态检查；厂商卡片能力与顺序同步。

- [x] 协议请求测试、串行及中断防重测试、前端构建、服务与页面检查。

## 验收界限

配置检查不等于 API 实际生成成功；无有效凭据的付费接口只做契约测试并明确说明。浏览器真实生成需实际输出和导入记录，不能用模拟测试冒充。
