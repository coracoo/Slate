# 三层视频创作台实施记录

依据：三层视频创作台设计 v2、角色音色资产与视频衔接设计，以及用户确认的三类提示词同步生成。

## 执行约定

- 在当前工作目录继续开发，保留已有未提交改动；不启动旧 MCP/自研浏览器扩展。
- storyboard JSON 保存 S 提示词及 V 编排；creation.json 保存不可变请求快照和结果。
- 不自动调用收费媒体模型验证；用契约测试、真实本地 FFmpeg、HTTP 和浏览器验证接线。
- 不因调用超时重发外部生成请求。无法确认提交结果时保持可排查状态。

- [x] 1. 分镜 LLM 同时生成 image/video/grid 三类提示词；编辑、旧文件兼容、重建不串用。

- [x] 4. 素材音色库、API 查询/试听/设计、角色绑定及台词配音。

## 当前进度

生产入口为 `/create`，原自由创作入口为 `/create/free`；音色入口为 `/studio/asset/voices`。本地构建已更新，服务已重载。

## 实现文件

- `production_prompts.py`：LLM 强制三类契约、作者文本、按消费阶段计算来源指纹。
- `production_studio.py`：相邻同场景 V、时长时间轴、乐观锁保存、人工内容保护、采用状态。
- `production_requests.py`：编译单次 S/V 请求、能力和引用预检、语义映射、共享负面词。
- `production_jobs.py`：不可变请求与素材副本、nonce 去重、后台执行、远端任务记录、采用与归档。
- `production_media.py`：真实尾帧、原关键帧宫格、统一音视频规格后拼接。
- `voice_assets.py`：音色列表/试听/设计、版本样音、角色绑定、逐句配音。
- 前端 `ProductionStudioView.vue`、`VoiceAssetsView.vue`、`durableRequest.ts`；分镜表同步增加三类编辑列。

## 仍需线上验收的边界

实现验收不等于供应商生成效果验收。本轮没有收费 LLM/生图/视频/TTS 调用；正式模型是否遵从多镜时序、人物/音色保真、image-use 浏览器真实出图必须用真实任务另行验证。远端任务超时保留 ID，不自动补发；当前恢复入口针对提交响应丢失，不承诺通用的跨厂商后台断点续跑。
