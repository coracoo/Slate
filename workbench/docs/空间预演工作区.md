# 空间预演工作区

镜头空间验证是制作流程中的可选工具。有站位、轴线、路径或机位疑问时使用；没有空间疑问的镜头可以直接继续创作生成。

## 三个视图的用途

| 视图 | 适合检查 | 输入与产物 | 使用边界 |
| --- | --- | --- | --- |
| 2D 平面 | 人物站位、对话轴线、运动路径、场景连通关系 | 分镜与场景资产；场景平面图、走位战略图 | 自动布局是空间提案；几何合法或判官通过不代表符合原片 |
| 动态白模 | 动作顺序、镜内走位和切镜节奏 | 分镜 JSON；白模视频、预演参考包 | 简化人形与陈设用于检查动作和时间，不表示最终表演或美术 |
| 3D 机位 | 机位视线、前后遮挡、景别与透视 | 含显式机位的 dialogue 分镜；Blender 场景、渲染视频 | 结论依赖输入的位置和尺寸；AI 拟定陈设需要核对 |

三个页面共用“镜头空间验证 · 可选”导航。桌面宽屏采用左侧选择与操作、右侧预览布局；窄屏按上下顺序展示。

## 操作收束

- 2D 平面保留场景或 V 列表。平面图生成针对场景；走位图的更新放在走位图页，拍摄资料的生成放在拍摄资料页。
- 动态白模把分镜、区间、引擎和镜头列表放在左侧，右侧显示联动播放。导出参考素材、从拉片生成示意分镜、历史产物按需展开。
- 3D 机位把构建与连接设置放在左侧，右侧显示预演与 Blender 场景。AI 补陈设、构建脚本与重发默认折叠。

## 数据与证据边界

镜头行为仍以分镜 JSON 为事实来源，预演页面不另存一份镜头安排。平面图沿用现有场景布局数据，走位图和资料包沿用现有派生链路。此次页面整理没有引入新的分镜契约，也没有更改生成接口。

拉片识别值经规则映射为机位、姿态和站位时，产物属于示意预演。原有 `origin` / `_generator` 来源字段继续承担逐项溯源；页面同时提示自动布局、陈设和机位需要人工核对。战略图沿用未匹配场景底图的提示，不能把回退底图当作空间一致性证据。

2D 与 3D 都不能自动证明精确复原。先核对场景关联与空间尺寸，再观察需要验证的镜头；如果输入缺少空间依据，应返回分镜或场景设定补充依据。

## 本次验证范围

本次仅整理页面布局、入口与说明，未修改真实项目数据，未运行付费生成或 Blender 渲染。验证包括前端既有测试与 Vue 模板编译；已登录页面的视觉回归需要可用的本机会话。
