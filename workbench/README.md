# Slate 工作台操作教程

首次安装请先完成 [仓库首页的 Windows 部署](../README.md#1-首次部署windows)。本页按当前界面介绍操作；所有命令默认在仓库根目录执行。

## 环境检查

最低 Python 3.12；推荐按首页使用 3.12 和带哈希的 Windows 依赖锁文件创建 `.venv`。先检查 Python、FFmpeg、所需依赖，再配置生成入口。无需全部服务商都开通；只配置要使用的能力。

- ComfyUI：先在本机启动 ComfyUI，再填写地址和实际安装的模型；工作流节点、文本编码器和模型架构必须匹配。选择任意模型文件名不代表默认工作流一定兼容。
- API：填写 Base URL、密钥与模型。测试/拉模型可直接使用正在编辑的配置；“启用”控制生成页面可选性。
- 火山：Agent Plan 与普通 API 两组独立。Plan 模型列表 404 时手动填写控制台确认的型号；不会自动改用普通 API 产生另一种计费。
- 媒体能力测试主要校验配置。实际模型权限、额度及参考素材可访问性需要真实任务确认。
- 模型配置在本机 `workbench/providers.json`。网页返回掩码，保存空密钥保留旧值；不要把配置提交到 Git。

### 批量安装

选择需要的依赖组，点击“后台安装所选环境”。任务面板提供安装日志，完成或失败时顶部提醒。刷新页面后可从任务面板继续查看。安装使用项目 Python 3.12 虚拟环境；基础依赖变更后重启前台服务。Chrome 扩展和账号登录需手动完成。

## ChatGPT 单张串行

### 安装

1. 环境检查 → **ChatGPT · chrome-use** → “复制一键安装命令”。使用虚拟环境时运行：

   ```powershell
   .\.venv\Scripts\python.exe workbench/tools/install_image_use.py
   ```

2. 安装 [chrome-use 扩展](https://chromewebstore.google.com/detail/chrome-use/knfcmbamhjmaonkfnjhldjedeobeafmk)，或使用环境页“下载上游扩展包”，解压后通过 `chrome://extensions` 的“加载已解压的扩展程序”安装。
3. 在 Chrome 启用扩展、完成授权并登录 ChatGPT。确保该账号能够正常手动生图。
4. 返回页面“重新检查”。安装器负责本机程序与 Native Messaging；浏览器登录由用户完成。

程序由 [image-use](https://github.com/leeguooooo/image-use) 和 [chrome-use](https://github.com/leeguooooo/chrome-use) 提供，Slate 不维护另一套私有网页上传 API。固定版本和安装说明见 [首页](../README.md#2-chatgpt-网页生图安装程序与浏览器扩展)。

### 排队、下载与导入

1. 在环境页启用 ChatGPT，素材生成页准备需要生成的任务。
2. 母素材按自身描述生成；派生状态/子素材按任务解析父参考图。先确认父图存在以及风格选择正确。
3. 将任务加入队列，启动 **ChatGPT · 单张串行**。每次只执行一张，参考图通过上游工具的 `-i` 逐张传入。
4. 下载结果后校验可读取性与尺寸，按任务绑定导入对应素材，再进入下一张。没有自动用视觉相似度猜测导入归属。
5. 遇登录、额度、页面变化或结果未知时，先检查保留的 ChatGPT 会话和本地日志。已有发送记录不自动重绘；恢复和重新生成不是同一操作。

运行记录位于项目 `创作/chatgpt_runs/`；请求与暂存文件位置以运行记录为准。执行期间不要并发操纵同一个浏览器生成任务。

仓库 `.codex/skills/video-previs` 提供独立的白模与拉片 Skill。

## 从剧本到视频

### 1. 分集、分镜与资产

新建制作项目后，在①剧本生成导入或扩写正文；在②分镜生成选择分集，生成并编辑镜头。分镜表中的提示词作为创作生成的默认内容，人工修改需要保存。

③素材生成可选择“全部”或具体分集。人物、场景、道具分别建档；人物和场景可有母图下的派生状态。视觉风格来自资产页“生图风格”及资产级覆盖，提炼文本负责外观事实。母素材无参考直出，派生图使用对应父图。

### 2. S / V / E 创作

- **S 转场镜头**：最小镜头单位，可生成参考关键帧，也可单独生成视频。
- **V 分镜视频**：相邻且场景连续的 S 组合，作为一次视频模型创作单元。
- **E 集视频**：采用各 V 视频后通过本地 FFmpeg 拼接。

创作生成采用三栏：左侧选集、编排模型与 V；中间编辑 V 和成员 S；右侧设置生成范围、模型、参考模式与时长。

1. 选择分集和具体文字模型，点 **自动合并分镜** 建立/更新 V 编排。同场景的派生状态是否连续仍需检查；不能只按名称相似就强制合并。
2. 每个 S 的参考帧、视频、宫格提示词独立可编辑，分别点 **重新生成 / 优化**，模型会根据当前框内文字优化。V 视频与宫格提示词也可编辑。静帧与连续动作提示词不互相代替。
3. 提示词使用镜号、时段、景别、机位、运镜、画面/人物/动作/声音/台词和光影描述；资产以 `@` 引用。S 时长修改联动 V 总长；右侧总时长也可修改并保存，提交时按模型范围校验。
4. 选择 S 并明确选择关键帧生成，生成后采用目标画面。点击 S 不会强制切换图片模式，仍可生成该 S 视频。
5. 选择 V，检查成员关键帧与视频提示词，再选择视频模型和参考模式提交。
6. 每个 V 采用完成视频后，点 **拼接已采用 V → 集视频**。提示词、时长或关键帧发生变化时，旧视频的采用状态需重新确认。

### 3. 关键帧、尾帧、音色

- 全能参考按 S 顺序引用已采用关键帧；可选择将真实关键帧在本地排成故事板宫格。宫格不是让模型另画一套分镜。
- 首帧/首尾帧模式需明确选择对应 S 关键帧，不与全能参考混用。
- **独立镜头**：不关联上段尾帧。
- **尾帧画面参考**：FFmpeg 截取上段尾帧，Vision 理解后加入连续性文字。
- **尾帧强制续接**：截取帧作为新视频正式首帧，要求模型支持。
- 角色音色按已适配模型能力引用；不支持时需单独配音，不能假装模型已收到音色。

缺参考图、关键帧过期、未知型号、超数量/时长或不兼容参数会拦截。视频结果自动归档到 `拉片素材/创作视频/`，可在拉片结构和逐帧页面继续处理。

## 音色、语音与音乐

④音色绑定中选择角色，拉取 API 音色库，生成试听并本地保存后绑定。支持 AI 音色创作和派生音色；角色绑定默认用于全剧，派生名称由用户明确编辑保存。设计试听与正式语音生成的验证状态分别记录。

- 音色：`素材/音色/<voice_asset_id>/r001/`，索引 `素材/音色/音色库.json`。
- 台词配音：从分镜 `lines` 读取，存 `素材/语音/`，关联角色、镜号和音色版本。
- 音乐：在⑧自由创作独立生成，存 `素材/音乐/`。
- 旁白为独立台词轨，不生成一个“旁白人物”资产。

## 本地音视频参考与公网素材出口

视频全能参考设置中的音频、视频支持 URL、本地上传和项目素材选择。上传分别存入 `素材/参考音频/`、`素材/参考视频/`。任务提交时复制并校验请求副本，不因原素材随后被覆盖而改变排队输入。

环境检查 → **公网素材出口**：填写 `https://media.example.com:8443/previs`。工作台自动拼接 `/api/public-reference` 和临时签名；有效期默认 86400 秒，可配置 1 小时至 7 天。

代理应将 `/previs/api/public-reference` 转发到本机同名接口，保留签名查询参数以及 Range、GET、HEAD。只公开这一读取接口。配置保存在被 Git 忽略的 `workbench/media_gateway.json`，签名密钥不返回前端。

保存成功仅表示格式有效：DNS、TLS/端口转发、代理、服务在线及云端可达仍需验证。不能把 `localhost`、内网 IP 或本机文件路径当成云端 URL。出口当前仅服务音视频；Agnes 图片仍需单独提供对应公网 URL。

## 拉片与白模

导入影片到项目“拉片素材”，进入拉片结构创建分析版本。台词以 ASR 为主，OCR 补漏；合并结果同步到分析镜头。逐帧提取、深度动作和白模为独立步骤，按需求执行。

拉片解构使用 `analysis.json`；白模使用分镜 JSON，需通过“从解构生成分镜”桥接。2D 白模用本机 Python 渲染；3D 白模还需 Blender，构建支持 Blender MCP，渲染可用 CLI。完整数据样例见 [examples](../examples/README.md)。

## 任务、产物与恢复

任务异步执行，顶部显示已完成或失败，任务抽屉保留日志。切页和刷新后继续跟踪，已有任务 ID 用于查结果，不重新提交收费生成。

- `创作/creation.json`：生成记录与产物索引。
- `创作/prod-<id>/request.json`：S/V 生成请求和素材副本。
- ComfyUI 按 `prompt_id` 轮询 history，并从输出节点回收。约千秒的生成不要求浏览器一直挂住请求；内置 H3 默认等待上限 3600 秒。
- 请求确认丢失时，用保留的 nonce 接管；不要清站点存储后重复点击生成。
- 画廊“清理异常”隐藏失败、异常及超过一天仍生成中的记录；后端数据保留，可恢复显示。它不等于取消上游任务。

## 常见问题

| 现象 | 处理 |
|---|---|
| 新功能、插件入口看不到 | 在 `workbench/web` 执行 `npm ci`、`npm run build`，重启后端并刷新；确认访问正确的 8775 实例 |
| chrome-use 显示已安装但不生成 | 检查 Chrome 扩展授权、Native Messaging、ChatGPT 登录/额度及运行日志；先手动验证账号生图 |
| 同一图片重复或结果不明 | 停止重复发送，核对保留会话与任务输出；当前队列坚持一次一张 |
| H3 返回 TokenPlan/Credit 不支持 | 配置具备 H3 按量 API 权限的账号/密钥；不是参考素材出口错误 |
| 公网素材超时 | 检查域名端口、代理路径前缀、签名有效期和服务在线；本机能访问不等于厂商网络可访问 |
| ComfyUI 维度/节点错误 | 确认模型架构、文本编码器、节点与 API 工作流匹配，不要只更换模型名 |
| Plan 拉模型 404 | 核对套餐 API 支持范围，必要时手填控制台确认的模型，不切到普通 API 兜底 |

源码部署、升级命令见 [首页](../README.md)。私人项目、密钥、日志、模型和依赖不随仓库分发，发布规范见 [SECURITY.md](../SECURITY.md)。
