# 白模方法论 — 空间符号与三分法（AI 视频时代的 Previs）

> 来源（2026-09 整理）：
> ① 弗曳哥《AI电影正式进入工业化时代》——DEADSHOT 片子：上半 AI 成片 / 下半 Blender 灰模逐镜并排，构图/机位/调度 1:1 对位；
> ② 无名NonameS《揭秘！我的最新AI视频创作助手—GPT6 Astra》——AI 助手自动生成 3D 色块预演（圆柱+球头人、走位路线图、机位扇形图），预演帧+提示词交 Seedance/Wan「重新渲染」出成片；
> ③ 小红书《AI导演经验｜Blender做视频参考的最佳方式》（Araki Neo）——Codex + Blender + Seedance 2.5 工作流长文。

## 一、核心原则

**1. 资产只是"空间符号"。**
角色 = 有固定名字和颜色的简单模型；车 = 长方体；墙 = 尺寸位置正确即可。
不为一个最终根本不会出现在成片里的预演，花时间做模型细节。

**2. 只把"必须确定"的信息交给 Blender：**
- 空间要确定（哪有墙、门在哪、两人隔多远）
- 机位要确定（镜头在哪、朝哪、怎么动）
- 人物关系要确定（谁站哪、谁先动）
- 关键动作节点要确定（何时侧移、何时倒地——只锁节点，不锁过程）

步伐、惯性、身体反应、细微表演**故意不规定**——提前规定死反而限制生成模型最擅长的生成能力。

**3. 三种信息分工（三分法）：**

| 载体 | 负责什么 |
|---|---|
| Blender 预演 | 空间关系、人物调度、摄影机运动、时间节奏 |
| 角色参考图（可加色卡，参考《万物生》工作流） | 长相、服装、装备、美术风格、整体色彩 |
| 提示词 | 表演：攻击、躲避、犹豫、惊慌、突然反应 |

**4. 武器/装备不在 Blender 里做全。**
角色参考图里有武器 + 提示词写清"正在持枪"就够，Blender 只保证手臂位置和大致动作关系。
3D 里武器/服装做得越具体，生成模型就多一层必须复制的东西。

**5. Blender 的定位：三维分镜 / Previs，不是低配动画。**
它解决二维分镜说不清的**空间问题**：人物从哪里出来、镜头从哪里拍、两人之间隔多远、谁先动谁后动、摄影机什么时候跟过去——一切场面调度问题。

## 二、端到端链路（三个实例共同验证）

```
拉片/剧本 → 空间符号白模（灰模+色块人+机位+关键动作节点）
         → 预演帧（干净画面）
         + 角色参考图（长相/服装/色彩）
         + 表演提示词（只写表演意图）
         → 图生视频模型（Seedance 2.5 / Wan 3.0 …）重渲染 → 成片
```

实例验证：弗曳哥 DEADSHOT（手持摄影/走廊枪战/POV，预演与成片逐镜对位）；无名 Astra（舞台走位图+机位扇形图→3D 预演→成片；"INSANELY COMPLEX MOVES"复杂运镜同样走预演→重渲染）。

## 三、对照本工作区系统

**已符合（天然同构）：**
- storyboard.json 唯一数据源；白模只锁机位/走位/轴线/景别/节奏/台词，不做美术 —— 与"必须确定的信息"清单一致
- PALETTE 固定服色角色 = "固定名字和颜色的简单模型"（空间符号）
- 每镜 prompt 字段 = 表演提示词槽位
- 拉片硬信息（切点/景别/角度/运镜/在场/骑马）进白模、微表演不进 —— analysis_to_storyboard 映射链
- 2D 引擎秒级迭代 + blender_previs 3D 预演（战场/军帐双场景、运镜关键帧）

**差距（落地路线，按优先级）：**
1. **干净帧输出**：白模画面现在烧了 HUD（镜号/运镜/提示词/台词）。人类预演没问题，但作为图生视频的参考帧，HUD 是污染。需引擎加 `overlay:false` / `--clean` 开关，预演帧出双份（带 HUD 给人看 + 干净帧给模型）。
2. **逐镜导出「预演帧+提示词」对**：导出器按镜出干净帧 + prompt.txt（表演意图，可由 prompt_cn 派生：剥离已由画面表达的机位/景别描述，保留动作/情绪），作为图生视频的输入包。
3. **角色参考图资产位**：约定 `projects/<项目>/素材/角色参考/<角色名>.jpg`（+可选色卡），导出包里登记清单；角色 PALETTE 即"空间符号色"，与参考图色卡呼应。
4. 关键动作节点 pose 扩展（持枪/举手/倒地等少量静态姿势）——只在 action 文本命中时启用；步态/惯性/口型继续不做。

## 四、一句话

白模的价值不在"建模"，而在**给生成模型建立一个可以理解的三维世界**：空间、机位、调度、节奏确定下来，剩下的交给生成。
