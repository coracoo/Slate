# 虚拟拍摄台（白模 Previs）· 使用说明

双击打开 `virtual_stage.html`（需联网加载 Three.js CDN；推荐 Chrome/Edge）。

## 这是什么
用代码搭的"数字白模拍摄台"：灰模替身角色 + 代码虚拟相机 + 走位/手势关键帧，
按分镜表实时预演运镜、构图、节奏，并叠加每镜的 Seedance 提示词。
用途：① 在生成前验证提示词效果；② 录成白模视频/截帧，当 AI 图生视频的结构参考。

## 界面
- 左下：当前镜号、内容、相机模式（keys 关键帧 / rig 越肩绑定）、时间码
- 右上：本镜提示词
- 右侧：镜头列表，点击跳转
- 底部：播放/暂停、进度条、**● 录制 WebM**（录完自动下载 `买瓜-白模previs.webm`）

## 已实现
- 代码运镜：推镜/跟拍/固定（keys），**越肩 OTS 相机直接绑到角色肩膀坐标**（rig，自动跟走位）
- 角色位移：骑摩托来 → 停车 → 走到摊前（路径关键帧 + 走路/骑车起伏）
- 骨架-lite：角色头随对话转向、摊主起身/手臂动作
- 非骨架刚体：摩托、西瓜、杆秤等道具
- 白模风格 + 阴天灰调，HUD 叠加提示词

## 怎么接 AI 视频（关键工作流）
1. 录制白模 → 在剪辑里把每镜**首帧/末帧**导出（或直接截关键帧）。
2. 白模帧当**首帧/多镜头参考图**喂给 Seedance/可灵（图生视频），配对应中文提示词：
   AI 负责"把灰模替换成真人真景 + 打光上色"，而**运镜、构图、走位、越肩轴线被白模锁死**。
3. 进阶：切深度图/相机轨迹做控制条件（Blender/UE 路线）。

## 如何改成你自己的分镜
编辑文件顶部 `shots` 数组即可，每镜字段：
- `cam`：`{type:'keys',from:[x,y,z],to:[...],look:'customer'|'vendor'}` 或
  `{type:'rig',actor:'customer',offset:[肩侧,高度,前后],look:'vendor'}`（越肩）
- `move`：角色/道具的 from→to 位移（`ride:true` 为骑车姿态）
- `turn`：谁转头看向谁；`gesture`：手势；`note`/`prompt`：HUD 文案

## 升级路线（真实 previs）
- 需要真实镜头畸变/景深/可导深度/骨架全身动画 → 用 **Blender + bpy 脚本**（同一套 shots JSON 驱动相机和绑定角色，渲染 OpenGL 白模或 EEVEE）。
- 需要多人复杂调度/灯光预览 → **Unreal Sequencer**。
- 本网页版优势：零安装、改 JSON 即所见、和分镜表一一对应，适合快速验证提示词。

## 角色卡片（贴图模式，下一步可加）
把三张定妆图（顾客/摊主/伙计）作为纹理贴到 billboard 面片或简模头部，
即可从"灰模"升级为"定妆图卡片预演"，脸部一致性在白模阶段就能看到。
